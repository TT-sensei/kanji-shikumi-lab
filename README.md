# 漢字のしくみラボ（仮称）

漢字を部品に分解して学ぶ、小学生向けの学習アプリです。
現在は **1・2・3年生の配当漢字440字のプロトタイプ** です（Phase 1のデータ整備＋Phase 2の試作を3年生まで拡張）。

## 遊び方（4モード＋唱える）

- **分解**：漢字をパーツごとに色分け表示。パーツをタップすると名前・場所・部首かどうかが分かる。
- **組み立て**：読みと例文をヒントに、パーツを選んで正しい場所に置き、漢字を完成させる。完成＝その字の「習得」。間違えた字は「にがて」に記録され、組み立てで成功すると消える（克服）。
- **構造**：左と右／上と下／囲み・かまえ／一つの形／組み合わせ、のどれかを当てる。
- **部首**：部首の名前を当てるクイズ。正解すると部首のパーツが赤く光り、場所の種類（へん・かんむり等）と、同じ部首の漢字が出る。
- **唱える**（横断機能）：分解・組み立ての画面で、その字の「唱え方」（部品を組み立て順に読み上げる短い言葉）を文字で表示する。音声読み上げは付けない。
- **パーツずかん**：部品の一覧から、その部品を含む漢字をたどれる。

学習状況は端末内（localStorage、名前空間 `kanjiShikumiLab.v1`）にモード別に保存されます。
ヒント機能は置いていません。困ったら分解モードで確認して戻る行き来が支援になります。

## 設計の決まり（2026-11-21 決定）

- 分解は自由分解ではなく、教材側が決めた**標準分解を1字1通りで固定**提示する。
- 部首と構成パーツは**別データ**として管理する（混同しない）。
- 習得の定義は「組み立てモードでターゲットの漢字を完成できたこと」。答えを見ただけでは習得にしない。
- 外部API・外部CDN・外部フォントは使わない。データは全て同梱し、オフラインで動く静的サイト。

## データの3層構造

| 層 | 中身 |
|---|---|
| `data/` | 外部データ由来。KanjiVG（分解・字形、CC BY-SA 3.0）、KANJIDIC2（部首番号・画数、EDRDG、CC BY-SA 4.0）。出典の詳細は `data/SOURCES.md` |
| `original/` | TT-sensei独自データ。学年・読み・例文（自作アプリ「かんじマスター」のデータが正）、唱え方・説明、部首名と位置分類の表 |
| アプリ本体 | `index.html` / `style.css` / `app.js`（画面・操作・学習機能） |

データ変換は `tools/build_data.py` で再生成できます（KanjiVGの分解のうち教育的に直した字は、同ファイルの `OVERRIDES` に理由とともに記録）。

## 動かし方

ローカルサーバーで開いてください（例：`python3 -m http.server` → `http://localhost:8000/`）。
タブレット横向き 1180×820 で、解く画面がスクロールなしに収まる設計です。

## 確認してほしい点（下書きのままの箇所）

- 唱え方・説明（`original/text1.json` / `text2.json` / `text3.json`）：唱え歌は確定版（3年生分はユーザーが他AIと作成し持ち込んだもの）。説明は1・2・3年生分とも下書きです。言葉の自然さと正確さの確認をお願いします。
- 部首の名前・位置分類：辞典の部首番号（KANJIDIC2）を土台に、子どもに出す名前と位置（へん／つくり／かんむり／あし／かまえ／そのほか）を付けた下書きです。部首名は漢和辞典の標準名を使い、KANJIDIC2の rad_name と照合しました（高の部首番号189は Unicode Unihan でも確認）。
- 構造分類：「組み合わせ」は、左右・上下・囲みに当てはまらない複合形の受け皿として置いた分類です。
- 分解の上書き（11字）：左・先・白・赤・本・虫・立・円・五・年・三＋森（林を木2つに分割）。`tools/build_data.py` の `OVERRIDES` 参照。
